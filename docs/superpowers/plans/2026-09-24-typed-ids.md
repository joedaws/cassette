# Typed Ids Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every session, cassette and writer id is `ses_`/`cas_`/`wri_` + a 26-character ULID, and a bare or wrong-kind id is rejected at every entry point.

**Architecture:** `store::ids` gains `IdKind`, `new(kind)`, `check(kind, s)`, `kind_of(s)` and `IdError`. Ids stay `String`s internally, and each entry point from outside calls `check`: CLI arguments, frontmatter, file and directory names, and `writers.toml`. The work is sequenced by id kind (sessions → cassettes → writers) so each task's fixture churn is limited to one kind and the suite stays green between tasks.

**Tech Stack:** Rust, `ulid` crate, clap, serde/toml; tests via `cargo test`.

**Spec:** `docs/superpowers/specs/2026-09-24-typed-ids-design.md`

## Global Constraints

- Format `<prefix>_<ULID>`; prefixes exactly `ses`, `cas`, `wri`; separator `_`; ULID part 26 Crockford chars, case-insensitive; total 30.
- No compatibility path for bare ULIDs anywhere in `src/`. The only trace is the skipped-directory count (Task 4).
- `.tmp-<ulid>` in `atomic_write` stays a bare ULID (it's not an identity), using `ulid::Ulid::new()` directly.
- Error wording, verbatim shapes: WrongKind: `` `{input}` is a {found} id; {slot} takes a {expected} id ({prefix}_…) ``. Malformed: `malformed {expected} id '{input}': expected {prefix}_ followed by a 26-character ULID`.
- Skipped line, verbatim: `{n} session directories skipped: names are not ses_ ids` (singular `directory` when n == 1).
- `writers.toml` with a bad key → `writers::read` returns `io::ErrorKind::InvalidData` naming the key.
- Clippy `-D warnings` green after every task. A new API lands in the same task as its first caller.

## Fixture rewrite rules (Tasks 1–3)

About 290 id literals live in tests. Rewrite them mechanically, by kind, in the task that starts validating that kind:

- A 26-character literal used as a **session** id → prefix `ses_`, unless the test is *about* a malformed id, in which case leave it bare and assert on the Malformed message.
- A literal used as a **cassette** id (e.g. `"aaa00000000000000000000000"`, `"01K5GR7T2M9WPD0000000000AB"`) → prefix `cas_`. Lowercase `a` is valid Crockford, so `cas_aaa00000000000000000000000` is well-formed.
- A **writer** id: `"w"`, `"writer-1"`, `"01WRITER0000000000000000AB"` (the `I` is not Crockford, so it is not a valid ULID today either) → the shared test constant from Task 3.
- `App` tests' session string `"01JTESTSESSN00000000000000"` is never validated by `App` and may stay. Change it only if a test routes it through the store.

## Review Focus

- **A hand-migrated store whose frontmatter `id` and file name disagree.** Expect a damaged row, not two cassettes. Task 2 test.
- **A lowercase-typed prefix (`SES_…`) or id.** Prefixes are lowercase only, and the ULID part is case-insensitive as today. `SES_…` is Malformed. Task 1 unit test.
- **A cassette id pasted into `resume`.** Expect "no session named …", not a crash or a WrongKind message. `resume` is alias-first and takes free text. Task 1 test.
- **`queue move --before <session id>`.** Expect exit 2 WrongKind naming `--before`. Task 2 CLI test.
- **An unmigrated store where only `writers.toml` was fixed.** Sessions are skipped and counted, and nothing crashes. Task 4 test.

```rust
/// Length of the ULID part of an id, after the `<prefix>_`.
const ULID_LEN: usize = 26;

/// The three kinds of identity the store mints. Each id carries its kind as
/// a prefix — `ses_`, `cas_`, `wri_` — so a person or an agent can tell a
/// session id from a cassette id from a writer id at a glance, and every
/// entry point can say *which* kind it was handed instead of "not found".
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum IdKind {
    Session,
    Cassette,
    Writer,
}

impl IdKind {
    const ALL: [IdKind; 3] = [IdKind::Session, IdKind::Cassette, IdKind::Writer];

    pub fn prefix(self) -> &'static str {
        match self {
            IdKind::Session => "ses",
            IdKind::Cassette => "cas",
            IdKind::Writer => "wri",
        }
    }

    pub fn noun(self) -> &'static str {
        match self {
            IdKind::Session => "session",
            IdKind::Cassette => "cassette",
            IdKind::Writer => "writer",
        }
    }
}

/// A fresh id of `kind`: `<prefix>_<ULID>`, roughly sortable by creation
/// time within a kind. Roughly is enough — the id is only ever a tiebreak.
pub fn new(kind: IdKind) -> String {
    format!("{}_{}", kind.prefix(), ulid::Ulid::new())
}

/// Why a string is not an id of the expected kind.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum IdError {
    /// Well-formed, but a different kind.
    WrongKind { expected: IdKind, found: IdKind },
    /// Not `<known prefix>_<ULID>` at all — a bare ULID included.
    Malformed { expected: IdKind },
}

impl IdError {
    /// The one wording every entry point uses. `slot` names where the id
    /// was given (`--session`, `<ID>`, `--before`).
    pub fn message(&self, input: &str, slot: &str) -> String {
        match *self {
            IdError::WrongKind { expected, found } => format!(
                "`{input}` is a {} id; {slot} takes a {} id ({}_…)",
                found.noun(),
                expected.noun(),
                expected.prefix()
            ),
            IdError::Malformed { expected } => format!(
                "malformed {} id '{input}': expected {}_ followed by a {ULID_LEN}-character ULID",
                expected.noun(),
                expected.prefix()
            ),
        }
    }
}

/// The kind of a well-formed id: a known lowercase prefix, `_`, then exactly
/// 26 Crockford base32 characters. `None` for anything else, a bare ULID
/// included.
///
/// This is the guard between an outside string and a path join
/// (`Store::session_dir`, `Store::cassette_path`): nothing that fails it
/// can contain `/` or `..`.
pub fn kind_of(s: &str) -> Option<IdKind> {
    let (prefix, ulid) = s.split_once('_')?;
    let kind = IdKind::ALL.into_iter().find(|k| k.prefix() == prefix)?;
    (ulid.len() == ULID_LEN && ulid.bytes().all(is_crockford_byte)).then_some(kind)
}

/// `Ok(())` when `s` is a well-formed id of `kind`.
pub fn check(kind: IdKind, s: &str) -> Result<(), IdError> {
    match kind_of(s) {
        Some(found) if found == kind => Ok(()),
        Some(found) => Err(IdError::WrongKind { expected: kind, found }),
        None => Err(IdError::Malformed { expected: kind }),
    }
}
```
